Compatibilidad Android y Microsoft Windows

Diseñado para funcionar sin interrupciones en ambos entornos

En Microsoft Windows
  • Instalable como aplicación de escritorio nativa desde Microsoft Edge o Chrome (clic en el icono de instalar en la barra de direcciones).
  • Funciona completamente sin conexión a internet (PWA offline).
  • Ejecutable con un clic mediante el archivo iniciar.bat.
  • Exportación directa a formato CSV compatible con Microsoft Excel.
En Teléfonos Android
  • Abre el navegador en tu teléfono con la dirección Wi-Fi local de tu PC o escanea el código QR.
  • Toca en el menú (⋮) y selecciona "Agregar a la pantalla principal" o "Instalar aplicación".
  • Se comportará como una app nativa con icono propio, barra inferior para pulgares y soporte táctil.
